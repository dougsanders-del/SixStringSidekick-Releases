Six String Sidekick 0.2.0 (23)

  • Lyric Ideas in Tablature: create original lyric drafts from a theme, mood and structure, edit them, then copy or append them to a song. Uses Apple's on-device model; requires macOS 26 or newer, a supported device, Apple Intelligence enabled and the model ready. No cloud service or API key.
  • Search Lyrics on song sheets and the loaded audio mini player opens your default browser. The app does not fetch, store or display searched lyrics.

macOS 14 remains the minimum for other app features. Lyric Ideas is disabled with an explanation when unavailable.
